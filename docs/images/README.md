# Screenshots (`docs/images/`)

Estes PNGs são **versionados no Git** e referenciados no [README.md](../../README.md) com caminhos relativos, por exemplo:

```markdown
![Descrição](./docs/images/swagger-home.png)
```

No GitHub, as imagens aparecem direto na página do repositório — não é import dinâmico nem CDN.

| Arquivo | Uso |
|---------|-----|
| `swagger-home.png` | Swagger `/docs` |
| `ui-perfil.png` | Aba Perfil |
| `ui-vaga-score.png` | Import de vaga + score |
| `ui-ranking.png` | Ranking ATS |

Para atualizar: substitua o PNG (mesmo nome) e faça commit.
